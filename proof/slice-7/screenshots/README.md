# Slice 7 Screenshots

The Playwright spec at `../playwright/slice-7.spec.ts` is what produces
the live dashboard screenshots. To capture them, run the spec against a
running dashboard:

```bash
DASHBOARD_URL=http://localhost:5173 \
  SLICE_7_AGENT=deliverability-expert \
  npx playwright test proof/slice-7/playwright/slice-7.spec.ts \
  --update-snapshots
```

This worktree did not run the spec live — the dashboard wasn't running
in this sandbox. Slice 1's QA notes the same constraint and committed
the spec for headless CI.

## Static artifacts

- `generated-avatar.png` — the placeholder avatar generated by
  `scripts/agent-gen-avatar.ts --placeholder` for the
  `deliverability-expert` test agent. Confirms the avatar pipeline
  emits a valid 256x256 PNG even without an API key.
